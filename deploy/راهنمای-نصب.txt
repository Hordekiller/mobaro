راهنمای نصب موبارو روی هاست cPanel
=====================================

پیش‌نیاز:
- PHP 8.1 یا جدیدتر
- افزونه‌های: pdo_mysql، mbstring، curl، fileinfo، openssl، intl
- SSL فعال روی دامنه
- Apache / LiteSpeed با پشتیبانی از .htaccess


مرحله ۱) ساخت دیتابیس
-----------------------
در cPanel وارد MySQL Databases شوید.
یک Database جدید بسازید (مثال: mobaro).
یک User جدید بسازید و ALL PRIVILEGES بدهید.


مرحله ۲) Import دیتابیس
-------------------------
در phpMyAdmin، دیتابیس ساخته‌شده را انتخاب کنید.
فایل database/install.sql را Import کنید.
(این فایل تمام جداول مورد نیاز را می‌سازد.)


مرحله ۳) آپلود فایل‌ها
------------------------
محتویات پوشه public_html این بسته را داخل public_html هاست آپلود کنید.
بهتر است ZIP را در File Manager آپلود و همان‌جا Extract کنید.


مرحله ۴) تنظیم .env
---------------------
در File Manager، فایل .env.example را Rename کنید و نام آن را .env بگذارید.
مقادیر زیر را ویرایش کنید:

  APP_URL=https://mobaro.ir
  DB_NAME=نام_دیتابیس
  DB_USER=نام_کاربر_دیتابیس
  DB_PASS=رمز_کاربر_دیتابیس
  ZARINPAL_MERCHANT_ID=شناسه_درگاه_زرین‌پال
  ZARINPAL_SANDBOX=false

تنظیمات SMS (اختیاری - بعداً از پنل ادمین قابل تنظیم):
  SMS_ENABLED=false
  SMS_API_KEY=کلید_کاوه‌نگار


مرحله ۵) تنظیم نسخه PHP
-------------------------
نسخه PHP دامنه را روی 8.1 یا بالاتر قرار دهید.


مرحله ۶) مجوز پوشه‌ها
-----------------------
مطمئن شوید پوشه‌های زیر قابل نوشتن باشند:
  storage/cache      (755 یا 777)
  storage/logs       (755 یا 777)
  storage/sessions   (755 یا 777)
  public/uploads     (755 یا 777)
  public/assets/uploads (755 یا 777)


مرحله ۷) ساخت اولین مدیر
--------------------------
در مرورگر باز کنید:
  https://mobaro.ir/setup-admin.php

نام، شماره و رمز عبور ادمین اولیه را وارد کنید.
بلافاصله فایل setup-admin.php را از هاست حذف کنید.


مرحله ۸) ورود به پنل
----------------------
  پنل مدیریت: https://mobaro.ir/admin/login
  سایت اصلی:  https://mobaro.ir


نکات امنیتی:
- HTTPS در .htaccess اجباری شده است.
- vendor داخل بسته موجود است (نیازی به Composer نیست).
- فایل .env و پوشه‌های حساس از دسترسی وب محافظت شده‌اند.
- فایل setup-admin.php را حتماً حذف کنید.
- اطلاعات کاربران واقعی در این بسته وجود ندارد.

نکات فنی:
- اگر از Cloudflare یا CDN استفاده می‌کنید، هدر X-Forwarded-Proto بررسی می‌شود.
- سشن‌ها با Secure و HttpOnly تنظیم شده‌اند.
- rate limiting روی ورود و فراموشی رمز فعال است.
- تنظیمات SMS از پنل ادمین قابل تغییر است.
